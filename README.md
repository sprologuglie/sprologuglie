# Guglielmo Sproloquio
Data analyst based in Turin. I turn messy data into reproducible analyses and interactive dashboards.
Background in quantitative research (bibliometrics, statistical modelling, agent-based simulation).

## Selected work
- **[Air Quality vs EU 2030 targets](https://github.com/sprologuglie/Air-Quality-and-EU-2030-OpenAQ)**: reproducible
  pipeline benchmarking city-level NO₂, O₃, PM₁₀, PM₂.₅ against
  EU standards.
  
  [Live app](https://air-quality-italy-and-eu-2030-openaq.streamlit.app/) · Python, OpenAQ, Streamlit
- **[Diversity in the philosophy of science](https://github.com/sprologuglie/A-scientometric-analysis-of-the-diversity-thesis-in-philosophy-of-science)**: code of my master thesis analysis of the effect of diversity on citation in recent philosophy of science articles.
  
  [Full analysis](https://sprologuglie.github.io/A-scientometric-analysis-of-the-diversity-thesis-in-philosophy-of-science/) · R, SOPHIS
- **[Epistemic ABM dashboard](https://github.com/sprologuglie/Interactive-Epistemic-ABM-Zollman-Using-Mesa)**: interactive simulation of
  how network structure shapes collective decisions.
  
  [Live demo](https://huggingface.co/spaces/sprolo-g/Zollman-bandit-interactive) · Python, Mesa, Solara
- *(next)* Energy transition dashboard: Terna + Eurostat
